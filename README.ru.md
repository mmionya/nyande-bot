# nyande-bot — Go edition

[English](README.md) | **Русский**

`nyande-bot` — Telegram- и Discord-бот для загрузки медиа с необязательным
Telegram LLM-ассистентом. Эта Go-версия включает полезные дополнения из
оригинальных Python- и Rust-проектов.

## Возможности

- загружает фотографии, видео и карусели из TikTok, Instagram, X/Twitter,
  Xiaohongshu (RedNote), Pinterest, YouTube и Reddit;
- прикладывает подпись или описание исходной публикации для всех поддерживаемых
  платформ;
- поддерживает прямые ссылки на изображения и видео;
- отправляет карусели Telegram-альбомами или пачками вложений Discord до 10
  файлов и проверяет ограничения размера;
- работает с OpenRouter и другими OpenAI-совместимыми API;
- передаёт LLM фотографии, выбранные кадры видео и расшифровку аудио или видео;
- восстанавливает весь сохранённый альбом, если пользователь отвечает на один
  из ранее отправленных ботом файлов;
- предоставляет LLM инструменты `current_time` и необязательный `web_search`;
- может удалять неподдерживаемые ссылки не-администраторов в группах;
- хранит дополнительные домены, разрешённые через `/allowlink example.com`;
- сохраняет настройку удаления ссылок для каждой группы после перезапуска;
- принимает Telegram Stars и может показывать необязательную кнопку Ko-fi;
- ведёт статистику процесса и отдельную историю LLM для каждого чата.

## Игры в чате

Команды `/ttt` и `/checkers` также запускают игры прямо через inline-кнопки
Telegram. Чтобы вызвать другого пользователя, ответь командой на его сообщение.

`/wordle` запускает Wordle прямо в чате. У всех игроков одно английское слово
дня из пяти букв и шесть попыток, но прогресс хранится отдельно
для каждого пользователя. После каждой попытки бот присылает PNG-карточку, а
на финальной карточке показывает аватар игрока.

## Стек

- Go 1.24 — Telegram- и Discord-боты, загрузчики и LLM-клиент;
- `yt-dlp`, Deno, FFmpeg и FFprobe — решение проверок YouTube, обработка медиа
  и резервные загрузчики;
- необязательный OpenAI Whisper CLI — локальная расшифровка аудио и видео;
- Docker Compose — запуск сервисов.

## Быстрый запуск

Требуются Podman или Docker с Compose-провайдером, а также Telegram-бот из
[@BotFather](https://t.me/BotFather), Discord-приложение или оба бота сразу.

1. Скопируй шаблон конфигурации:

   ```bash
   cp .env.example .env
   ```

2. Укажи в `.env` хотя бы один токен. Оба транспорта могут работать
   одновременно:

   ```dotenv
   BOT_TOKEN=123456789:telegram_bot_token
   DISCORD_BOT_TOKEN=your_discord_bot_token
   ```

3. Собери и запусти все сервисы:

   ```bash
   docker compose up -d --build
   ```

   Та же команда для Podman:

   ```bash
   podman compose up -d --build
   ```

4. Проверь состояние и логи:

   ```bash
   docker compose ps
   docker compose logs -f bot
   ```

   При использовании Podman замени в этих командах `docker compose` на
   `podman compose`.

Python-зависимости устанавливаются через `uv` с кешем загрузок. Слой Whisper
собирается отдельно от бинарника бота, поэтому изменения Go-кода не запускают
установку Whisper заново при обычной сборке с кешем. Первая установка PyTorch
и CUDA-зависимостей всё ещё может занять время.

Стандартный образ `runtime` включает локальный Whisper. Если расшифровка не
нужна, используй уменьшенный образ:

```dotenv
DOCKER_TARGET=runtime-lite
WHISPER_ENABLED=false
```

## Настройка Discord

Создай приложение и бота в
[Discord Developer Portal](https://discord.com/developers/applications),
скопируй токен в `DISCORD_BOT_TOKEN` и включи **Message Content Intent** на
странице Bot. При
приглашении на сервер выдай права на просмотр каналов, отправку сообщений и
файлов, а также чтение истории сообщений. Бот обрабатывает первую
поддерживаемую медиассылку в сообщении и отвечает скачанными файлами.

По умолчанию доступны команды `!help`, `!ping`, `!stats` и `!gif`. Префикс меняется
через `DISCORD_COMMAND_PREFIX`. LLM, модерация, платежи и игры в чате пока
остаются функциями Telegram-бота.

## LLM и анализ медиа

Пример конфигурации OpenRouter:

```dotenv
LLM_ENABLED=true
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_API_KEY=your_api_key
LLM_MODEL=perplexity/sonar-pro
LLM_TRIGGER_WORDS=мяу,нянде
LLM_WEB_SEARCH_ENABLED=false
LLM_VISION_ENABLED=true
LLM_TIMEZONE=Asia/Almaty
LLM_VIDEO_FRAME_COUNT=3
WHISPER_ENABLED=true
```

Perplexity доступен через тот же ключ OpenRouter: укажи модель
`perplexity/sonar-pro`. Она использует собственный поиск, поэтому для неё можно
оставить `LLM_WEB_SEARCH_ENABLED=false`. Для остальных моделей OpenRouter
значение `true` подключает серверный поиск с движком Perplexity. Бот использует
результаты в ответе, но не добавляет отдельный список ссылок.

История каждого чата сохраняется в `LLM_HISTORY_FILE` и переживает перезапуск
контейнера; `/reset` удаляет её и из памяти, и с диска. Длинные ответы
автоматически делятся на несколько сообщений без обрезания текста.

Долговременная память хранится отдельно в базе SQLite по пути
`LLM_MEMORY_FILE`. Записи привязаны одновременно к чату и пользователю, поэтому
профили участников группы не смешиваются. Модель получает до
`LLM_MEMORY_RECALL_LIMIT` релевантных или недавних записей и может сохранить или
удалить одну из них только через отдельные инструменты памяти. Явные пароли,
API-ключи и токены отклоняются. Функцию можно отключить через
`LLM_MEMORY_ENABLED=false`.


В личном чате бот отвечает на обычные текстовые и медиа-сообщения. В группе его
можно вызвать упоминанием `@username`, ответом на сообщение бота или одним из
слов в `LLM_TRIGGER_WORDS`. Слова перечисляются через запятую, сравнение не
зависит от регистра. На скачанное и отправленное ботом медиа он отвечает только
тогда, когда в сообщении есть одно из этих триггерных слов.

`LLM_VIDEO_FRAME_COUNT` задаёт количество равномерно выбранных кадров видео и
принимает значения от 1 до 6. `LLM_TIMEZONE` принимает IANA-имя, например
`Asia/Almaty`, или смещение UTC, например `+05:00`.

Сообщения чата сохраняются в базе данных SQLite с поддержкой полнотекстового поиска FTS5
по пути `CHAT_LOG_FILE`. LLM имеет доступ к инструментам `search_chat_messages` (поиск по истории
сообщений чата) и `get_recent_messages` (получение недавних сообщений для контекста). Чтобы бот в группе
получал абсолютно все сообщения (а не только при прямом обращении), отключите Privacy Mode в `@BotFather`
(`/setprivacy -> Disable`) или назначьте бота администратором группы. Функцию можно отключить через `CHAT_LOG_ENABLED=false`.

Все доступные настройки перечислены в [`.env.example`](.env.example). Файл
`.env` исключён из Git; никогда не публикуй токены бота и API-ключи.

Администратор группы может использовать `/linkdelete on` или `/linkdelete off`,
чтобы включить или выключить удаление неподдерживаемых ссылок. Настройка хранится
в `LINK_MODERATION_FILE` и по умолчанию выключена.

## Команды бота

| Команда | Назначение |
|---|---|
| `/start` | запустить бота |
| `/help` | показать справку |
| `/ttt` | крестики-нолики в сообщениях Telegram |
| `/checkers` | шашки в сообщениях Telegram |
| `/wordle` | Wordle из пяти букв в сообщениях Telegram |
| `/donate` | поддержать бота через Telegram Stars или Ko-fi |
| `/paysupport` | показать информацию о поддержке платежей |
| `/ping` | проверить доступность бота |
| `/stats` | показать статистику текущего процесса |
| `/reset` | очистить историю LLM текущего чата |
| `/remember факт` | сохранить долговременное воспоминание для пользователя и чата |
| `/memory` | показать долговременные воспоминания и их номера |
| `/forget номер` | удалить одно долговременное воспоминание по номеру |
| `/forget_all` | удалить всю долговременную память пользователя в этом чате |
| `/round` | конвертировать видео в видеосообщение-кружочек |
| `/voice` | конвертировать аудио или видео в голосовое сообщение |
| `/gif` | конвертировать видео в зацикленную анимацию (гифку) |
| `/mediainfo` | показать характеристики фото, видео или аудио (разрешение, FPS, кодеки) |
| `/allowlink example.com` | разрешить домен в личном чате или от имени администратора |
| `/linkdelete [on\|off]` | настроить удаление неподдерживаемых ссылок в этой группе |

В Discord доступны `!help`, `!ping`, `!stats` и `!gif` (либо другой префикс из
`DISCORD_COMMAND_PREFIX`). Для скачивания медиа команда не нужна — достаточно
отправить ссылку. Для `!gif` прикрепи видео, добавь поддерживаемую ссылку
или ответь командой на сообщение с видео. Бот отправит GIF без звука
(15 кадров/с, ширина до 480 пикселей); размер ограничен `MAX_FILE_SIZE`.

## Локальная проверка

```bash
gofmt -w cmd internal resources
go test ./...
go vet ./...
```

Для работы бота требуются `yt-dlp` с компонентом EJS, Deno, `ffmpeg` и
`ffprobe`. Docker-образ уже включает их. Для локальной расшифровки
дополнительно нужен CLI `whisper`.

## Структура репозитория

```text
cmd/nyande-bot/     точка входа приложения
internal/bot/         команды, игры, модерация, медиа и состояние
internal/telegram/    клиент Telegram Bot API
internal/discordbot/  Discord gateway, команды и ответы с медиа
internal/downloader/  загрузчики платформ и yt-dlp fallback
internal/llm/         OpenAI-совместимый клиент и инструменты
resources/            общий strings.json
```

Загружай и распространяй только контент, на который у тебя есть права или
разрешение автора.

## Цитатник

Ответь `/quote` на текстовое сообщение или подпись к медиа: бот сохранит
цитату и отправит PNG-карточку с именем, доступной аватаркой автора и датой.
Для пересланных сообщений используется исходный автор, если Telegram его передал.
Лимит — 1200 символов; форматирование и анимированные эмодзи в карточку не переносятся.

- `/quote random` — случайная цитата текущего чата.
- `/quote list` — последние 10 цитат и их номера.
- `/quote 12` — открыть цитату №12.
- `/quote delete 12` — удалить цитату; доступно автору, сохранившему её участнику и администраторам.

Коллекции чатов изолированы, повторное сохранение одного сообщения не создаёт
дубликат. Данные хранятся в SQLite (`QUOTE_DB_FILE`); в Compose база находится
в постоянном томе `/app/data/quotes.db`. Функция не требует LLM и доступна в Telegram.

## Поиск и отправка медиа через LLM

Можно попросить: «Нянде, найди короткое видео с котом и пришли сюда» или
«Найди фото капибары и отправь картинкой». С включённым
`LLM_WEB_SEARCH_ENABLED=true` модель находит ссылку и вызывает `download_media`.
Инструмент принимает URL публикации поддерживаемой платформы или прямую ссылку
на изображение/видео и отправляет файлы в текущий Telegram-чат. Обычные статьи
и страницы поисковой выдачи не являются ссылками для загрузки.

Применяются ограничения `MAX_FILE_SIZE` и `MAX_MEDIA_ITEMS`. На одну попытку
выделяется до трёх минут; повторы одной ссылки в рамках запроса не отправляют
дубликаты. Ошибка или частичная отправка возвращаются модели как результат
инструмента. Доступность ролика зависит от исходного сайта и настроек загрузчика.

## Журнал действий

`docker compose logs -f bot` показывает события `[command]` (имя команды,
чат, пользователь, сообщение и время выполнения), `[media]` (начало/результат
загрузки, источник, тип/имя/размер файлов и результат отправки), `[tool]`
(вызовы инструментов LLM) и `[search]` (результаты локального поиска).
Команды и медиа журналируются для Telegram и Discord.
Аргументы команд и содержимое ответов инструментов в эти события не включаются;
в поле URL загрузки убираются логин, пароль, параметры запроса и фрагмент.
`[tool] returned` означает завершение вызова инструмента; фактический результат
отправки файлов виден в `[media] sent` или `[media] send_failed`.

Для запросов о TikTok доступен инструмент `search_tiktok` (при включённом веб-поиске): поиск ограничен TikTok, в выдаче остаются только уникальные ссылки на отдельные видео. В OpenRouter используются ссылки из цитат серверного поиска; при ошибке или отсутствии подходящих ссылок — DuckDuckGo. Затем `download_media` может скачать и отправить выбранный ролик. Это поиск по индексируемым страницам, без гарантии свежести, популярности или доступности скачивания. Серверный поиск использует дополнительный LLM-запрос; новые ключи API не нужны.
