# Музыка в Discord

Войди в обычный голосовой канал и отправь команду в текстовый канал того же сервера.
Префикс ниже — `!`; если задан `DISCORD_COMMAND_PREFIX`, используй его.

| Команда | Действие |
|---|---|
| `!search название` | Пять результатов поиска YouTube |
| `!search sc: название` | Поиск SoundCloud |
| `!play 2` | Второй результат твоего поиска в этом текстовом канале (действует 10 минут) |
| `!play название` | Найти и запустить первый результат YouTube |
| `!play https://youtu.be/...` | Запустить трек по ссылке YouTube или SoundCloud |
| `!queue` | Текущий трек и очередь |
| `!skip` | Следующий трек |
| `!pause` / `!resume` | Пауза / продолжение |
| `!stop` / `!leave` | Остановить, очистить очередь и выйти из голосового канала |

Повторный `!play` добавляет трек в очередь, максимум 50 ожидающих треков.
Очереди разделены по серверам и не сохраняются после перезапуска.
Когда очередь заканчивается, бот выходит из голосового канала.
Управлять проигрывателем могут участники того же голосового канала.
Поиск и просмотр очереди не требуют входа в голосовой канал.
Музыка работает независимо от `!llm off`. Каналы-трибуны (Stage) не поддерживаются.
При ссылке на плейлист загружается только первый трек, а не весь плейлист.

Боту нужны права **Просматривать канал**, **Подключаться**, **Говорить** в голосовом
канале и право отправлять сообщения в текстовом канале.

## Запуск с Docker Compose

Из каталога проекта:

```bash
docker compose --profile music up -d --build
```

Профиль `music` запускает Lavalink 4.2.2 с YouTube-плагином 1.18.2.
Бот подключается к `lavalink:2333`. `LAVALINK_ADDRESS` в `.env` можно оставить пустым
для этого варианта; Compose подставит адрес сервиса.
`LAVALINK_PASSWORD` должен совпадать у бота и Lavalink; Compose передаёт его обоим.
Порт Lavalink на хосте доступен только через `127.0.0.1:2333`.

## Если бот работает через systemd

Можно оставить Go-бота в systemd, а через Docker запустить только аудиосервис:

```bash
docker compose --profile music up -d lavalink
```

В `.env`, который читает служба бота, задай:

```dotenv
LAVALINK_ADDRESS=localhost:2333
LAVALINK_PASSWORD=youshallnotpass
LAVALINK_SECURE=false
```

Пересобери Go-бота с Go **1.25+**, установи бинарник по пути из `ExecStart` своей
службы и перезапусти её. Например, если служба называется `nyande-bot`:

```bash
go build -trimpath -o nyande-bot ./cmd/nyande-bot
# Скопируй бинарник по пути ExecStart своей службы.
sudo systemctl restart nyande-bot
```

Если Lavalink размещён отдельно, укажи его `host:port`; для HTTPS/WSS установи
`LAVALINK_SECURE=true`. Пустой `LAVALINK_ADDRESS` при запуске без Compose отключает
подключение к аудиосервису. Бот устанавливает соединение при первой музыкальной команде.

## Диагностика

```bash
sudo journalctl -u nyande-bot -f
docker compose logs -f lavalink
```

YouTube иногда ограничивает доступ с адресов серверов. В этом случае проверь логи
Lavalink и [настройки YouTube-плагина](https://github.com/lavalink-devs/youtube-source#plugin),
либо попробуй `!play sc: название` для SoundCloud.
Отключение аудиосервиса или потеря голосового соединения может очистить очередь;
после восстановления запусти трек снова. Бот сообщает об ошибках воспроизведения
в текстовом канале, где запущена музыка.

Почему нужен отдельный аудиосервис: Discord требует DAVE для голосовых подключений,
а Lavalink поддерживает его начиная с 4.2.0:
[объявление Discord](https://discord.com/blog/bringing-dave-to-all-discord-platforms),
[изменения Lavalink](https://lavalink.dev/changelog/v4).
