# Музыка в Discord

Войди в обычный голосовой канал и отправь команду в текстовый канал того же сервера.
Префикс ниже — `!`; если задан `DISCORD_COMMAND_PREFIX`, используй его.

| Команда | Действие |
|---|---|
| `!search название` | Пять результатов поиска YouTube |
| `!search ytm: название` | Поиск YouTube Music |
| `!search sc: название` | Поиск SoundCloud |
| `!search bc: название` | Поиск Bandcamp |
| `!play 2` | Второй результат твоего поиска в этом текстовом канале (действует 10 минут) |
| `!play название` | Найти и запустить первый результат YouTube |
| `!play https://youtu.be/...` | Запустить трек по ссылке YouTube, YouTube Music, SoundCloud или Bandcamp |
| `!queue` | Текущий трек и очередь |
| `!skip` | Следующий трек |
| `!pause` / `!resume` | Пауза / продолжение |
| `!stop` / `!leave` | Остановить, очистить очередь и выйти из голосового канала |

Повторный `!play` добавляет трек в очередь, максимум 50 ожидающих треков.
Очереди разделены по серверам и не сохраняются после перезапуска.
Когда очередь заканчивается, бот выходит из голосового канала.
Управлять проигрывателем могут участники того же голосового канала.
Поиск и просмотр очереди не требуют входа в голосовой канал.
Музыка работает независимо от `!llm off`. Каналы-трибуны (Stage) не поддерживаются.
При ссылке на плейлист загружается только первый трек, а не весь плейлист.

Боту нужны права **Просматривать канал**, **Подключаться**, **Говорить** в голосовом
канале и право отправлять сообщения в текстовом канале.

## Запуск без Java и Docker

По умолчанию `DISCORD_MUSIC_BACKEND=direct`: голосовое соединение открывает
[DisGo](https://github.com/disgoorg/disgo), DAVE обрабатывает
[dave-go](https://github.com/thomas-vilte/dave-go). Поиск и получение аудиоссылки
выполняет `yt-dlp`, FFmpeg преобразует поток в Opus (48 кГц, стерео, 64 кбит/с).
Java, отдельный аудиосервис и нативная библиотека libdave не требуются.

На хосте нужны FFmpeg с кодировщиком `libopus`, свежий `yt-dlp` с компонентом EJS
и Deno для проверок YouTube. Если загрузка видео уже работала, эти программы,
скорее всего, установлены. Проверяй их от пользователя службы бота:

```bash
yt-dlp --version
ffmpeg -version
ffmpeg -encoders | rg libopus
deno --version
```

Для Debian/Ubuntu можно установить FFmpeg и выделенное окружение yt-dlp:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg python3-venv
python3 -m venv ~/.local/share/nyande-media
~/.local/share/nyande-media/bin/pip install -U 'yt-dlp[default]'
```

Deno должен быть доступен в `PATH` службы, как описано в
[требованиях yt-dlp](https://github.com/yt-dlp/yt-dlp#dependencies).
В `.env`, который читает служба бота, укажи:

```dotenv
DISCORD_MUSIC_BACKEND=direct
MUSIC_MAX_PLAYERS=1
YTDLP_PATH=/home/USER/.local/share/nyande-media/bin/yt-dlp
FFMPEG_PATH=/usr/bin/ffmpeg
```

Замени `USER` на пользователя, установившего yt-dlp. Если он уже доступен в `PATH`
службы, можно оставить `YTDLP_PATH=yt-dlp`. Для cookies используются существующие
`YTDLP_COOKIES_FILE` / `YTDLP_COOKIES_FROM_BROWSER`.

Пересобери бот с Go **1.26+**, установи бинарник по пути `ExecStart` своей службы
и перезапусти её. CGO не нужен. На хосте с 512 МБ лучше собирать на другом
компьютере под ОС/архитектуру хоста и переносить готовый бинарник.

```bash
CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o nyande-bot ./cmd/nyande-bot
# Установи бинарник по пути ExecStart своей службы.
sudo systemctl restart nyande-bot
sudo journalctl -u nyande-bot -f
```

Если служба называется иначе, подставь её имя.

### Переход с Lavalink

Сначала обнови бинарник и установи `DISCORD_MUSIC_BACKEND=direct`, затем перезапусти
бота. Старые `LAVALINK_*` в этом режиме игнорируются. Если твоя отдельная служба
Lavalink называется `lavalink`, её можно остановить и убрать из автозапуска:

```bash
sudo systemctl disable --now lavalink
```

Для старого контейнера: `docker compose --profile music stop lavalink`.
Новый запуск музыки больше не требует этого процесса.

### Память и ограничения

По умолчанию разрешён **один голосовой проигрыватель на весь бот**, включая все
Discord-серверы (`MUSIC_MAX_PLAYERS=1`). Поиски и получение аудиоссылок выполняются
последовательно: одновременно работает не более одного музыкального процесса
yt-dlp. FFmpeg использует один поток кодирования; в памяти остаются только
небольшие буферы, а не весь трек. Поиск возвращает до 20 результатов.

Это убирает расход памяти JVM, но не гарантирует, что весь бот вместе с ОС,
Whisper, загрузкой видео и остальными службами поместится в 512 МБ. Для такого
хоста держи `WHISPER_ENABLED=false`. `GOMEMLIMIT=128MiB` можно задать для Go-процесса
как мягкий ориентир сборщика мусора; он не ограничивает yt-dlp, FFmpeg и Deno.
После запуска музыки проверь память службы и её дочерних процессов:

```bash
systemctl show nyande-bot -p MemoryCurrent -p MemoryPeak
systemd-cgtop
```

Пауза приостанавливает отправку кадров, а не скачивает песню целиком. Изменение
громкости перезапускает FFmpeg с текущей позиции, поэтому возможно короткое
прерывание; для прямых эфиров переподключается к текущему месту трансляции.
При остановке, пропуске или закрытии бота дочерние процессы завершаются.
Внешнее отключение или перенос бота в другой голосовой канал очищает очередь;
запусти `/nyande play` снова для нового подключения.

### Docker

В образ уже входят yt-dlp, Deno и FFmpeg. Для варианта без Whisper:

```dotenv
DOCKER_TARGET=runtime-lite
DISCORD_MUSIC_BACKEND=direct
MUSIC_MAX_PLAYERS=1
WHISPER_ENABLED=false
```

```bash
docker compose up -d --build bot
```

Профиль `music` включать не требуется.

### Диагностика источников

YouTube / YouTube Music ищутся через yt-dlp, SoundCloud — через `scsearch`,
Bandcamp — через публичную страницу поиска треков. Источники `yt:`, `ytm:`, `sc:`
и `bc:` работают с `!search` и `!play`; по умолчанию используется YouTube.
Прямые HTTPS-ссылки этих сайтов тоже поддерживаются. Наличие длительности и
обложки зависит от метаданных сайта; Bandcamp в поиске может не отдавать длительность.

Сайты могут ограничивать адрес сервера или требовать cookies. Bandcamp иногда
возвращает браузерную проверку: бот сообщает об ошибке поиска. Обнови yt-dlp,
проверь cookies/Deno или попробуй другой источник. Диагностика доступна в
`journalctl -u nyande-bot -f` (или `docker compose logs -f bot`).

### Необязательный прежний транспорт

Для обратной совместимости оставлен `DISCORD_MUSIC_BACKEND=lavalink`. Только в
нём используются `LAVALINK_ADDRESS=host:2333`, `LAVALINK_PASSWORD` и
`LAVALINK_SECURE`. В Compose можно отдельно запустить
`docker compose --profile music up -d lavalink` и задать
`LAVALINK_ADDRESS=lavalink:2333`. Конфигурация узла — `resources/lavalink.yml`.
На хосте с 512 МБ этот вариант не нужен.

## Поиск и проигрыватель с кнопками

После перезапуска обновлённый бот регистрирует группу slash-команд `/nyande`.
Приложение должно быть установлено на сервере с доступом `applications.commands`.
Для карточек в текстовом канале боту нужны права **Отправлять сообщения** и
**Встраивать ссылки (Embed Links)**.

- `/nyande search` открывает форму поиска. Можно сразу передать `query` и выбрать
  `source`: YouTube Music, YouTube, SoundCloud или Bandcamp. По умолчанию — YouTube.
- Результаты видны только автору запроса. До 20 треков в прямом режиме, по 10 на странице:
  название, исполнитель, длительность и доступная обложка.
- В выпадающем списке можно выбрать несколько треков. Выбор сохраняется между
  страницами. «Добавить выбранные» добавляет их в порядке исходного списка.
  Повторное нажатие не добавляет дубликаты. При нехватке места в очереди весь
  выбранный набор отклоняется; можно уменьшить выбор и повторить.
- «Назад» возвращает к выбору источника, «Новый поиск» открывает форму.
  Результаты действуют 10 минут, не сохраняются после перезапуска.
- `/nyande play query:... source:...` запускает или добавляет один трек.
- `/nyande player` показывает общую карточку проигрывателя. Она также появляется
  после добавления треков из окна поиска или через `/nyande play`.

Карточка содержит название, исполнителя, источник, обложку (если доступна),
время и полосу прогресса. Обновляется примерно раз в 15 секунд и после нажатия
кнопок; позиция в прямом режиме считается по отправленным аудиокадрам.
Кнопки: пауза/продолжение, пропуск, повтор, перемешивание, остановка, громкость
−10/+10 и очередь. После остановки кнопки отключаются. На сервер поддерживается
одна карточка в канале её создания. При удалении карточки повтори `/nyande player`.
Старые карточки после перезапуска бота больше не управляют проигрывателем.

Дополнительные команды:

| Команда | Действие |
|---|---|
| `/nyande queue` | Показать текущий трек и ожидающие треки лично тебе |
| `/nyande skip`, `/nyande pause`, `/nyande resume`, `/nyande stop` | Управление воспроизведением |
| `/nyande shuffle` | Перемешать ожидающие треки |
| `/nyande clear` | Удалить ожидающие треки, оставив текущий |
| `/nyande move from:1 to:3` | Переставить трек в очереди; текущий трек не нумеруется |
| `/nyande repeat mode:track` | Повторять текущий трек; также доступны `queue` и `off` |
| `/nyande volume value:50` | Громкость 0–100%; начальное значение — 50% |
| `/nyande help` | Справка |

Текстовые команды остаются доступны. Дополнительно: `!shuffle`, `!clear`,
`!move 1 3`, `!repeat off`, `!repeat track`, `!repeat queue`, `!volume 50`.
Для изменения воспроизведения и добавления треков нужно находиться в голосовом
канале бота. Смотреть очередь и искать музыку можно без входа в голосовой канал.
Пропуск трека не повторяет его, даже если включён повтор текущего трека.

Это интерфейс поиска **треков**. Отдельного поиска исполнителей/альбомов/плейлистов
как коллекций пока нет.

## Проверки реализации

Пройдены тесты очереди/интерфейса и проверки гонок данных, обработка Ogg/Opus,
пауза/громкость/отмена процессов, локальная передача UDP с транспортным
шифрованием. Реальные поиски YouTube, YouTube Music и SoundCloud вернули по
20 результатов; реальный поток SoundCloud преобразован в 100 кадров Opus.
Bandcamp вернул браузерную проверку. Подключение и DAVE-переговоры с живым
голосовым каналом Discord в этой среде не проверялись.

Отдельный локальный замер кодирования синтетического аудио показал около
51 МиБ пикового RSS у FFmpeg. Это не замер всей службы и не обещание вместиться
в 512 МБ: yt-dlp, Deno, Go-бот и ОС учитываются отдельно.
